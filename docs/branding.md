The display name is OrbitCell. Use OrbitCell Studio for the full product name,
page title and package metadata. The npm package and repository use
`orbitcell-studio`.

New deployments can use the `ORBITCELL_` environment prefix. Existing
`AGENTHUB_` variables remain compatible; the new spelling takes precedence.
Stored sessions, provider credentials, database filenames, browser preferences
and integration identifiers are preserved. Renaming the product does not move
the data directory or reset an installation.
